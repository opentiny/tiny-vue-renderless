# Events

| 事件名            | 说明             | 参数                                    |
| ----------------- | ---------------- | --------------------------------------- |
| change            | 切换 tab 时      | tab: Tab                                |
| close             | 关闭 tab 时      | tab: Tab                                |
| add               | 新建标签页       | 无                                      |
| address-enter     | 地址栏回车       | url: string, tab: Tab                   |
| go-back           | 点击后退按钮     | tab: Tab                                |
| go-forward        | 点击前进按钮     | tab: Tab                                |
| refresh           | 点击刷新按钮     | tab: Tab                                |
| minimize          | 点击最小化按钮   | 无                                      |
| maximize          | 点击最大化按钮   | 无                                      |
| window-close      | 点击关闭窗口按钮 | 无                                      |
| star              | 点击收藏按钮     | tab: Tab, starred: boolean |
