# Props

| 名称            | 类型    | 默认值 | 说明                            |
| --------------- | ------- | ------ | ------------------------------- |
| tabs            | Array   | —      | 标签页数组，见下方 Tab 结构     |
| modelValue      | String  | —      | 当前激活 tab 的 name（v-model） |
| drug            | Boolean | false  | 是否允许拖拽排序                |
| canGoBack       | Boolean | false  | 后退按钮是否可用                |
| canGoForward    | Boolean | false  | 前进按钮是否可用                |
| addressEditable | Boolean | true   | 地址栏是否可编辑                |
