# frontend

## Pre-requisites

The document depends on the tiny-engine project, so you need to initialize the submodule first.

```shell
git submodule update --init --recursive
git submodule update --remote
```

Obtaining the Document Update Time

```shell
npm run obtainDocTime
```

## Project setup

```shell
yarn install
```

### Compiles and hot-reloads for development

```shell
yarn dev
```

### Compiles and minifies for production

```shell
yarn build
```
