# 区块管理

区块管理是区块的管理侧，物料面板上的区块是区块的消费侧。消费侧的区块是单纯的使用区块，管理侧则是对区块的统一管理，可对区块增删改查。

- 新建区块

  1. 点击新建区块按钮（图-1）
  2. 弹出新建区块的弹窗，输入正确的区块名称（必填）和路径（必填），点击确定后，会在空白画布渲染当前区块，弹出物料面板
  3. 用户只需托拉拽组件或区块到画布上，点击工具栏的保存按钮，这时候区块才是真正创建完成。
  4. 点击发布按钮（图-15）发布区块，只有发布成功的区块才能被消费

2. 属性设置

   我们的区块不是封闭的，是可以接受属性传值的。这里设置的是区块暴露的属性，也是消费区块的时候，显示在属性面板提供给用户设置的属性。区块允许暴露属性，因此消费区块的时候，传递参数给区块，区块内部可以根据参数自定义区块的逻辑。

3. 事件设置

    我们的区块不仅可以接受属性传值还可以暴露事件和消费它的页面交互。

4. 生命周期

  区块和页面一样，也有自己独立的生命周期。

5. 历史备份

   发布区块和发布页面一样，可以输入本次的改动点信息，记录历史备份。历史备份信息可以预览和还原到这条历史记录
