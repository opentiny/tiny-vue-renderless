# 关于物料资产包

## 如何定制组件与区块

可视化设计器已为您提供官方组件库与一些区块，物料资产包创建完成后会自动打开编辑页面，用户可以在这里添加组件库与区块，如下图：

* **添加组件库:** 选中未选择的组件库
![添加组件库](md-only-prefix/img/docimg/createMaterialLib.png)

* **添加区块：** 选中未选择的区块
![添加区块](md-only-prefix/img/docimg/createMaterialBlock.png)

* **移除组件库：** 取消选中已经选择的组件库，并且确认
![移除组件库](md-only-prefix/img/docimg/createMaterialLibCancel.png)
  
* **移除区块：** 取消选中已经选择的区块，并且确认
![移除区块](md-only-prefix/img/docimg/createMaterialBlockCancel.png)

* 用户也可以在生态中心录入自己的组件库与区块。
