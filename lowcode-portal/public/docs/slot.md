# 声明插槽

我们可以在区块中声明插槽，继而在使用区块时可在插槽中插入内容

## 操作步骤

- 打开区块管理面板，新建区块
![](md-only-prefix/img/docimg/slot1.png)

- 编辑区块，在区块中添加Slot组件
![](md-only-prefix/img/docimg/slot2.png)

- 保存、发布区块
![](md-only-prefix/img/docimg/slot3.png)



# 使用插槽

分为两种插槽，一种是区块的插槽，另一种是组件的插槽

## 组件插槽

有一些组件自带插槽属性，比如表格组件(注意，表格组件的插槽下的元素可用\"row\"参数来获取行数据)
![](md-only-prefix/img/docimg/slot4.gif)

## 区块插槽使用

拖动带有插槽的区块带画布中，再拖动想要插入的元素到区块中即可
![](md-only-prefix/img/docimg/slot5.gif)
