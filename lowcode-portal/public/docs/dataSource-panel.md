# 数据源管理

数据源面板对数据源进行系统管理，包含新建数据源、数据源的设置功能，与`Collection`组件结合使用

- 新建数据源
  1. 点击新建数据源按钮（图-2）
  2. 选择数据源数据类型（图-8）
  3. 设置数据源名称（图-9）
  4. 点击获取远程字段按钮（图-11）
  5. 设置数据源描述（图-13）
  6. 设置数据的 URL（图-14）
  7. 设置请求方式（图-15）
  8. 设置请求参数（图-16）
  9. 设置页面运行态时，页面初始化是否加载服务。编辑态时使用 Mock 数据（图-17）
  10. 发送真实 Http 请求，只有真实的 url，请求方式，和参数，才可以发送成功
  11. 设置请求结果的字段，数据源会根据请求结果的字段设置数据源字段，如果是发送的真实请求，会根据请求结果填充，否则需要需要手动填写完整
  12. 设置是否发送请求（图-19）
  13. 设置请求前处理（图-20）
  14. 设置请求完成的处理函数（图-25）
  15. 设置请求失败的回调函数（图-26）
  16. 点击取消（图-23）取消获取远程字段的设置，点击保存（图-24）则是保存获取远程字段的设置
  17. 保存后会弹出远程字段列表的设置页面，点击保存
  18. 在点击保存数据源（图-7），数据源创建完成
  19. 点击数据源列表（图-4），会弹出数据源字段的表格，可新增 Mock 数据，用于编辑态的时候显示使用，运行态时会调用用户设置的真实服务
