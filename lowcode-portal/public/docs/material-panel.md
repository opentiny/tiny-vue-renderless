# 物料面板详细介绍

> `物料`，顾名思义就是我们拖拽生成一个页面所需要用到的所有基本材料，分为 `组件` 和 `区块` 。我们可以拖拽物料面板上的组件或区块到中心画布上，灵活地排布出想要的页面

<img src="http://image.opentiny.design/tiny-lts/v1/images/59603f8645b08cb64cb2f8b91c983bc0_1917x879.png"  width="1400"/>

## 组件

组件面板展示的组件来自于创建设计器时选择的`物料资产包`中所包含的组件，如需更多组件，可前往 `我的设计器`&rarr;`编辑设计器`&rarr;>`选择物料资产包`选择更加丰富的资产包！

**组件面板信息：**

- 分类

  我们拥有丰富的组件库！
  分为 `内置组件`、`表单组件`、`提示组件`、`数据组件`、`容器组件`、`布局组件`，方便根据分组快速查找相关组件

<img src="http://image.opentiny.design/tiny-lts/v1/images/97c0a6346bde378f896054a2726b3687_1909x976.png"  width="1400"/>

- 搜索

  组件面板提供搜索框输入`组件名称`的关键字快速搜索

<img src="http://image.opentiny.design/tiny-lts/v1/images/391403f1e41c2dcf5bd90ceade7473ef_1821x1126.gif"  width="1400"/>

- 固定面板

  点击固定面板按钮，就可以将物料面板固定在左侧，拖拽组件到画布后，面板也不会收起。再次点击按钮即可解除固定。

- 关闭面板

  手动关闭物料面板

<img src="http://image.opentiny.design/tiny-lts/v1/images/afaffd148a5d4629f388a372b51dd007_1909x933.png"  width="1400"/>

## 区块（消费侧）

  物料面板上的区块，是消费态的区块，具有有以下特点：

- 可拖拽至画布渲染，是页面的重要组成组成部分
- 可在属性面板配置区块的属性、事件
- 可重复使用，提高开发效率
- 消费区块的时候，在画布上只可选中区块，不可选中区块内的组件

**区块面板信息：**

- 分组(图-1)

  默认有一个**设计器默认区块分组**，如需更多分组，可点击新增分组按钮添加新的分组。可以切换分组快速筛选区块。

- 新建分组(图-2)

  点击新建分组按钮(图-2) => 打开分组设置面板 => 选择区块作为当前分组的区块(图-3) => 保存(图-4)

- 给当前分组添加区块(图-6)

  点击添加区块按钮(图-6)=>打开分组设置面板=>在可选区块列表选中区块(图-3)=> 保存(图-4)

- 搜索(图-5)

  组件面板提供搜索框输入`区块名称`的关键字快速搜索

- 固定面板(图-12)

  点击固定面板按钮，就可以将物料面板固定在左侧，拖拽区块到画布后，面板也不会收起。再次点击按钮即可解除固定。

- 关闭面板(图-13)

  手动关闭物料面板
