# 页面管理

页面管理是对当前应用下的所有页面的统一管理，涉及每个页面或者文件夹的增删改查。页面管理面板图解：

<img src="http://image.opentiny.design/tiny-lts/v1/images/b08ef31750d0d86abb03bbf3e02c4e39_1918x927.png"  width="1400"/>

- 新增文件夹
  1. 点击新建文件夹按钮（图-1）
  2. 设置 **基本设置**：
     设置文件夹名称（图-19）=> 设置该文件夹的父文件夹（图-20） => 设置该文件夹的路由（图-21）
- 新建页面

  1. 点击新建文件夹按钮（图-2）
  2. 设置 **基本设置**：
     设置页面名称（图-19）=> 设置该页面的父文件夹（图-20） => 设置该页面的路由（图-21）
  3. 设置**主页**（图-22），设置当前页为主页，一个应用只可有一个主页。被设置为主页的页面会有（图-7）的标志
  4. 设置输入输出（图-15）
  5. 设置页面的根节点元素，有 Body 和 Div 两种，默认为 Div（图-16）
  6. 设置页面生命周期（图-17），点击+号会显示对应的生命周期，可添加对应生命周期的代码（图-23）
  7. 每次点击保存按钮（图-29），可记录本次保存的信息，展示在历史备份的列表，**预览按钮**（图-24）可对对应版本进行查看，**回退按钮**（图-25）可回退页面至当次的保存的数据。

- 页面分组

  页面分为静态页面和公共页面两组。静态页面可以创建文件夹和页面，公共页面只可以创建页面。

- 页面搜索

  用户可以根据页面名称进行模糊搜索（图-3）

- 编辑页面/文件夹的配置

  鼠标悬浮在页面/文件夹上，点击设置按钮（图-13），可打开页面、文件夹的设置面板，设置后保存即可。

- 页面上锁状态

  用户点击锁定页面按钮（图-12），可对当前页面进行上锁，或对自己上锁的页面解锁。页面列表的绿色圆点（图-8）表示用户可以锁定编辑的页面，而红色圆点，则代码被其他用户锁定的页面，需要联系对应的用户解锁，方可锁定编辑。
