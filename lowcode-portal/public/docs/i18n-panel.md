# 国际化资源管理

国际化可用作多种语言的切换，目前设计器支持中文和英文的多语言切换，国际化面板用于管理所有国际化数据

<img src="http://image.opentiny.design/tiny-lts/v1/images/438f97b2f81827546febcb851dbf16c3_391x565.png"  width="600"/>

### 国际化词条操作

- 新增词条，输入中文和英文，键值为自动生成

![新增词条](http://image.opentiny.design/tiny-lts/v1/images/f8f1b9b600f42f03a2a577416e83defc_495x688.gif)

- 搜索功能支持模糊搜索

![模糊搜索](http://image.opentiny.design/tiny-lts/v1/images/b7eb917ad7fca5f73f86e4581d6e57f7_495x688.gif)

- 编辑国际化词条

![编辑](http://image.opentiny.design/tiny-lts/v1/images/f9d08e7564c1f91cd8f8b6faaf6adc3e_495x688.gif)

- 支持删除不需要的国际化

![删除](http://image.opentiny.design/tiny-lts/v1/images/9d3f4a109dcf12d5c007e84467df431d_1285x688.gif)



### 国际化词条的绑定使用

- 国际化词条绑定：在画布中选中对应的组件，在右侧设置面板点击国际化绑定 icon，选择需要绑定的词条

![词条绑定](http://image.opentiny.design/tiny-lts/v1/images/714e46b05e47bfaa18a03604addb5c01_1813x908.gif)

- 国际化词条效果预览：需点击预览，然后切换顶部语言，即可预览国际化词条效果
